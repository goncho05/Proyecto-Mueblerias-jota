# Mueblería Hermanos Jota — E-Commerce

Proyecto de e-commerce estático para la materia de Desarrollo Web. Presenta la fachada completa de la Mueblería Hermanos Jota con experiencia de compra interactiva del lado del cliente.

## Tecnologías Utilizadas
* HTML5: Marcado semántico y accesibilidad.
* CSS3: Diseño responsivo (Mobile First) y Flexbox.
* JavaScript: Manipulación del DOM, eventos, simulación asíncrona (Promise / setTimeout) y gestión de datos locales (localStorage).
* Git & GitHub: Control de versiones con estrategia de ramasy Pull Requests.

## Funcionalidades Principales
* Página de Inicio (index.html): Hero banner y renderizado dinámico de productos destacados.
* Catálogo (productos.html): Grilla completa de muebles con buscador en tiempo real.
* Detalle de Producto (producto.html): Vista ampliada con ficha técnica y botón de compra.
* Contacto (contacto.html): Formulario con validación JS en vivo.
* Carrito Simulado: Contador global en el header que persiste la cantidad al navegar.
